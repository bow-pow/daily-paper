Localize-and-Stitch: Efficient Model Merging via Sparse Task Arithmetic

Yifei He, Yuzheng Hu, Yong Lin, Tong Zhang, Han Zhao
The Brief

This research introduces a smarter way to combine multiple specialized AI models into one, without losing their individual strengths.

Instead of trying to blend all the tiny pieces (parameters) of each model, which often causes them to interfere with each other, this method cleverly finds and extracts only the most important, small "skill sets" from each specialized model. These identified skill sets, which represent a tiny fraction of the total model, are then carefully stitched back into the original, general-purpose model. This localized approach avoids the performance degradation seen in older, global merging techniques.

This is interesting because it suggests we can build more capable AI systems by combining existing ones efficiently, potentially leading to smaller, more manageable AI that can learn and adapt new skills without forgetting old ones.

Background

Imagine you have a powerful AI model, like one that can understand and generate text. This model has learned a lot about language in general from a massive amount of data. Now, you want to teach it to do specific tasks, like answering questions about science or summarizing news articles. You do this by "finetuning" the model, which means further training it on data for that specific task. This works well, but you end up with many different finetuned models, each specialized for a different job. Storing and managing all these individual models becomes a problem. Model merging is a way to combine the strengths of these specialized models into a single, unified model that can handle multiple tasks. The challenge is that simply averaging all the parameters of these finetuned models often leads to "task interference," where the learned skills for one task negatively impact the performance on another, degrading the overall capability of the merged model.

What they did

This research proposes a new method called "Localize-and-Stitch" to address the problem of task interference in model merging. Instead of merging all the parameters of the finetuned models, which is a "global" approach, Localize-and-Stitch takes a "localized" approach. It works in two main steps:

1.

Localization

The core idea here is that when a model is finetuned for a specific task, only a small, specific set of its parameters actually learns the crucial new skills for that task. The rest of the changes might be redundant or even harmful. This step aims to identify these "tiny localized regions" within each finetuned model that are responsible for its specialized abilities. They found that these essential regions often represent only about 1% of the total model parameters. To find these regions, they use a mathematical process that optimizes a "binary mask" for each task. This mask essentially tells the model which parameters are important for that specific task. They also offer a "dataless" version of this step, which selects parameters that changed the most during finetuning, useful when no task-specific data is available for fine-tuning the mask.

2.

Stitching

Once these small, important regions (represented by the masks) are identified for each finetuned model, they are "stitched" back onto the original, general-purpose pretrained model. This means only these selected, sparse regions are integrated, rather than the entire finetuned model. If multiple tasks happen to have identified important parameters in the same location (an "overlap"), they average the contributions from those tasks to handle the conflict. This process aims to combine the specialized skills without introducing significant interference.

What they found

The experiments show that Localize-and-Stitch significantly outperforms existing model merging methods, both when validation data is available and when it's not (the "dataless" version). For instance, on language tasks, their dataless approach achieved a performance increase of over 10% compared to standard methods like task arithmetic and even surpassed some methods that *do* use validation data. When using validation data, their method achieved the highest average accuracy on both language and vision benchmarks. A key finding is that by localizing only about 1% of the parameters, they can recover over 99% of the performance of a fully finetuned model for that task. This localization also leads to a drastic reduction in model size, compressing the storage needed for the specialized skills to about 1% of the original finetuned model size. Furthermore, the method effectively preserves the knowledge of the original pretrained model, mitigating "catastrophic forgetting" that often occurs with finetuning.

Why it matters

This research offers a more efficient and effective way to combine the capabilities of multiple specialized AI models. Instead of dealing with the performance degradation caused by simply averaging models, Localize-and-Stitch intelligently selects and integrates only the essential learned skills. This has several important implications:

*

Efficiency

It allows for the creation of a single model that can perform many tasks, reducing the storage and computational costs associated with deploying many individual models. The compressed representation of skills is a significant advantage. *

Performance

It leads to better overall performance on multi-task scenarios by minimizing task interference. *

Flexibility

The method is adaptable to situations with varying data availability and is particularly well-suited for "continual learning," where new skills can be added incrementally without retraining everything from scratch. *

Interpretability

The localized regions can be seen as compact and interpretable representations of the skills learned for each task, offering insights into how different tasks relate to each other.

In essence, Localize-and-Stitch provides a practical solution for building more capable and manageable AI systems by smartly combining specialized knowledge.
