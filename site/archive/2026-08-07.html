Eigen Attention: Attention in Low-Rank Space for KV Cache Compression

Utkarsh Saxena, Gobinda Saha, Sakshi Choudhary, Kaushik Roy
The Brief

This research introduces a new method called Eigen Attention to make large language models (LLMs) handle longer texts more efficiently.

The core idea is to compress the memory used by LLMs when processing long inputs. LLMs use something called a "KV cache" to store information about previous parts of the text, which becomes a major memory hog for long contexts. Eigen Attention cleverly performs the crucial "attention" operation, which helps the model understand relationships between words, in a smaller, "low-rank" space. This significantly reduces the size of the KV cache without much loss in the model's ability to understand text.

This matters because it could lead to LLMs that can process much longer documents, like entire books or complex legal texts, on existing hardware, making them more practical for a wider range of real-world applications.

Background

Large language models (LLMs), like the ones powering advanced chatbots and AI assistants, are incredibly powerful. A key factor in their ability to understand and generate text is the "context length" – how much text they can consider at once. Researchers are keen to increase this context length to tackle more complex tasks, such as summarizing entire books or analyzing lengthy codebases. However, a significant hurdle emerges when dealing with long contexts and processing many requests simultaneously (a "large batch size"). This hurdle is the "KV cache." The KV cache is a memory component that stores intermediate calculations (keys and values) related to the attention mechanism, which is how LLMs figure out which words are most important to each other. When the context gets long and batch sizes are large, this KV cache swells up, consuming an enormous amount of memory and slowing down the entire process. It becomes the primary bottleneck, essentially turning LLM inference (how the model generates responses) into a memory-bound problem.

What they did

To tackle this KV cache bottleneck, this research proposes "Eigen Attention." The core idea is to perform the attention calculation in a "low-rank space." Think of it like this: instead of storing and processing all the detailed information in the keys and values, Eigen Attention finds a smaller, more fundamental set of "basis vectors" that can represent most of this information. This is inspired by the mathematical concept of Singular Value Decomposition (SVD), which can break down a matrix into its most important components.

Here's how it works: 1.

Calibration

They take a small, representative sample of text data (a "calibration dataset") and run it through the LLM to generate "representation matrices" for the queries, keys, and values. 2.

Basis Vector Generation

Using SVD on these representation matrices, they identify the most important "basis vectors" that can capture the essence of the original data. The number of these basis vectors determines the "rank" of the low-rank space. A lower rank means fewer vectors and thus more compression. 3.

Projection and Integration

These basis vectors are then used to "project" the original query, key, and value information into this lower-dimensional space. Crucially, these projections are integrated directly into the LLM's existing weight matrices. This means that during inference, the model naturally computes lower-dimensional keys and values.

The result is that the KV cache, which stores these keys and values, becomes much smaller. This approach is "orthogonal" to other KV cache compression methods, meaning it can be used alongside them for even greater savings. They also address compatibility with different positional encoding schemes, like Rotary Positional Embeddings (RoPE), which are common in modern LLMs.

What they found

Eigen Attention demonstrated significant improvements in both KV cache size and inference speed. Across various LLM families (OPT, MPT, and Llama) and sizes, they achieved up to a

40% reduction in KV cache size

. This directly translates to less memory being used. Furthermore, they observed up to a

60% reduction in attention operation latency

, meaning the model can generate responses faster. This speedup is particularly pronounced in models where the KV cache is a major bottleneck. While there's a slight drop in performance (measured by perplexity and accuracy on various tasks), it's minimal, especially for larger models and with moderate compression levels. For instance, with a 40% KV cache compression, the OPT-66b model showed only a 1% drop in zero-shot accuracy. They also found that combining Eigen Attention with other compression techniques, like token pruning, could lead to even greater savings.

Why it matters

The primary impact of Eigen Attention is making LLMs more efficient, especially for tasks requiring long contexts. By drastically reducing the memory footprint of the KV cache, it allows LLMs to handle longer sequences without running out of memory. This opens the door to more sophisticated applications that were previously impractical due to memory constraints. It also means that LLMs can be deployed on hardware with less memory, making them more accessible. While the research shows minimal performance degradation, it's important to note that extreme compression can lead to a more noticeable drop. The authors suggest that fine-tuning the compressed model can help recover some of this lost performance. The work highlights that the ability to compress the KV cache is crucial for unlocking the full potential of LLMs for complex, long-context tasks.
